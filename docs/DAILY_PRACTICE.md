# 每日一练与升级说明

## 2026-09-27 源码更新

每日一练按独立课程进度从现有题库选择题目。它不再依赖知识文档、教材节点、Embedding 或 Qdrant；知识库问答与索引仍需这些服务。Worker 在知识索引服务暂不可用时，仍可启动每日调度、课程匹配、题库导入和作答状态回填。

- 教学主题支持多课次、授课日期修正、暂停、考试日期及修订历史。主题最后一次授课后，在次日北京时间 04:00 解锁；考试日结束后退出选题。
- 自动匹配读取题目及配图并输出课程主题，低置信度、歧义和证据不充分的结果转人工校正。题目内容或主题语义修改会使旧匹配失效；单独调整日期不重复执行语义匹配。
- 只有启用、批准、章节有效且主题匹配有效的人工/导入题进入候选。跨主题题必须涉及的全部主题都已学，固定题也执行同样的范围校验。候选按游标遍历完整合格集合，然后分配课程与近期/复习/覆盖配额。
- 默认个性化部分为 7 题，固定题另外计算，整份练习最多 1 道简答题。题目可以包含私有配图；新增图片、删除图片和更新题目会使相关匹配与未开始计划失效。
- 保留 AI 计划、一次无效 MAX 响应纠错和确定性回退。计划发布与开练再次核对版本；已开始、已完成的作答保留快照。
- 总开关关闭时，管理员可为少量活动用户开启内部测试。暂停时段仍然生效；总开关开启后按正常规则开放。新安装不预设内测用户。
- 人工重新冻结未开始计划时，生成截止时间至少延至执行时间后 30 分钟，保留原本更晚的截止时间；自动重建不持续延长窗口。已开始、已完成及暂停计划不被强制重开。
- 题库管理支持配图和分页，答题结束后错误题号显示为红色。旧 AI 出题与出题审核入口、执行器已移除，历史题目、审核和作答数据模型保留；`AI_GENERATED` 题目不进入新普通练习和每日计划。

## 配置自己的课程

公开版的 `packages/daily-practice-core/src/curriculum-source.ts` **仅包含五课次的虚构示例**，使用 `example-term` 和 2030–2031 年日期，不是任何班级的真实课表。它不会随迁移或管理员初始化自动写入业务库；不要把示例直接当作当前教学进度。

1. 首次构建与课程初始化前，将该文件中的学期、开始日、考试日、课次标题和日期替换为自己的授权课程资料。日期使用 `YYYY-MM-DD`。同一主题的连续编号课次会合并，完成最后一次课后才解锁。
2. 当前实现限定两门医学学科，课程代码 `MCG`、`MORPH` 分别对应 `medical-molecular-cell-genetics` 和 `human-morphology-function`。如需换成其他学科，需要一起调整 `curriculum.ts` 的学科范围/映射及相关验证，不能只修改显示名称。
3. 管理员在「每日一练 → 教学进度」初始化课程。初始化只补齐同一学科学期的缺失记录，不覆盖已有课程。初始化后改源文件也不会更新已有记录；日期和主题修订应通过管理接口/界面及预期版本提交。
4. 导入或创建自有题目，核对学科章节，在「题目主题校正」检查自动匹配和人工待审结果。仅调整课程日期不会解除未通过的主题匹配。
5. 先使用少量自有测试账号检查内测权限、生成、配图、答题提交和刷新后的记录，再按需开启总开关。真实 AI、COS 及数据库流程必须在自己的部署环境验收。

## 运行参数

`.env.example` 是开发参考，`infra/runtime.env.example` 是安装器生产默认模板；实际配置保存在仓库外的私有目录。默认并发保持 1，部署者应依据自身机器、题库图片量和供应商额度调整。

| 参数 | 默认值 | 用途 |
| --- | ---: | --- |
| `AI_CURRICULUM_MAPPING_TIMEOUT_MS` | 180000 | 单次课程匹配超时 |
| `AI_CURRICULUM_MAPPING_DAILY_CALL_LIMIT` | 1000 | 每日匹配调用上限 |
| `AI_CURRICULUM_MAPPING_DAILY_TOKEN_LIMIT` | 10000000 | 每日匹配 token 上限 |
| `AI_DAILY_PLAN_TIMEOUT_MS` | 300000 | 每日计划请求超时 |
| `AI_DAILY_PLAN_CONCURRENCY` | 1 | 每日计划生成并发 |
| `AI_DAILY_PLAN_MAX_INPUT_TOKENS` | 32000 | 计划输入预算 |
| `AI_DAILY_PLAN_MAX_OUTPUT_TOKENS` | 32000 | 计划输出预算 |
| `AI_DAILY_PLAN_DAILY_CALL_LIMIT` | 200 | 每日计划调用上限 |
| `AI_DAILY_PLAN_DAILY_TOKEN_LIMIT` | 20000000 | 每日计划 token 上限 |
| `DAILY_PRACTICE_JOB_LEASE_MS` | 600000 | 任务租约，须覆盖相关请求超时及结算余量 |

额度不是容量承诺。图片请求另有限制；课程匹配与每日计划共享主机、数据库、模型账户及网络。不要把一台部署的历史容量结论套用到另一环境。

## 从旧版本升级

新增正式迁移 `20260924090000_daily_curriculum_decoupling` 和 `20260925071958_daily_internal_test_access`，完整目录共 28 个迁移。新增课程、课程修订、题目匹配、个人题目状态，以及题目内容版本和内测用户设置；不导入课表、照片、成员或题目。

升级已有实例前，备份数据库、uploads、COS、Qdrant 和解密密钥，并在隔离恢复环境演练迁移。停止旧 Worker 领取 AI 出题任务，等待在途任务妥善结束；新版 Worker 不再处理旧出题队列，历史记录不得自动清空。

为 API 和 Worker 的私有运行配置加入三个 `AI_CURRICULUM_MAPPING_*` 参数，核对上表预算和租约，移除不再使用的 `AI_QUESTION_GENERATION_*` 参数。`deploy.py init` 面向首次安装，不会自动改写已有私有配置，不要在旧实例上重新初始化。

构建匹配版本的 Web/API/Worker，发布前后检查 `prisma migrate status`，使用正式 `prisma migrate deploy` 执行迁移。不要 `db push`、在非空数据库 seed 或重建数据卷。代码切换后先初始化自己的课程、核对主题匹配并验证完整业务流程，再扩大开放范围。

回滚前检查旧程序是否认识新增枚举和已写入的新数据，不能单独切回旧 Worker 并假定兼容。源码验证范围见 [VALIDATION.md](VALIDATION.md)。本次仅发布源码，未部署在线服务。
